# Scientific limitations

- The sequence engine supports nucleotide FASTA/FASTQ. The API also imports bounded OpenGenome2 JSONL portions by extracting nucleotide-only examples from common fields; this is not a general JSONL corpus parser. Protein alphabets and paired-end linkage are not supported.
- FASTQ is interpreted as four-line records with Phred+33 scores. Wrapped FASTQ and alternate historical quality encodings are not supported or inferred.
- Exact duplicate detection compares complete uppercase sequence strings. Reverse-complement equivalence is reported separately using canonicalized reverse-complement keys; near-duplicate matching is not implemented.
- Raw top k-mer counts are exact and retain strand orientation. Additional reverse-complement-canonical spectrum and GC-count heatmap summaries are exact for the current process; no sketching, disk partitioning, or genome-size model is implemented.
- Shannon entropy is computed per whole sequence and in fixed 100-base windows stepped by 25 bases; low-complexity regions use a fixed 1.2-bit threshold and are descriptive. Homopolymer values are descriptive indicators. No clinical, taxonomic, contamination, or assembly quality conclusions are made from them.
- Assembly N50/N75/N90, L50/L75/L90, and the cumulative Nx curve are length-only contiguity calculations gated by an explicit assembly classification. No NG statistic, completeness, or contamination score is provided.
- Rule-based findings use configurable thresholds and support acknowledgement/dismissal. They do not establish biological significance.
- OpenGenome2 supports selected FASTA shards and bounded plain-JSONL prefix import. JSONL extraction recognizes nucleotide-only values in common sequence/text fields and retains detected tags/special tokens as provenance; it is not a general training-corpus parser. NCBI RefSeq metadata search uses the optional NCBI Datasets CLI and does not download genome packages. GTDB release directory discovery and user-supplied CSV/TSV taxon mappings are supported; automated GTDB taxonomy mapping/classification, reference sequence import/comparison, BUSCO, QUAST, and CheckM2 execution remain unavailable.
- The parser and API currently retain sequence records/results in process memory. The default 5 GiB upload cap is not a promise that files of that size can be analyzed on a developer laptop. Use small local datasets and tune resource limits conservatively.
- There is no authentication or multi-user authorization. Local path import is restricted to configured roots. URL import requires an explicit hostname allowlist, public DNS addresses, HTTPS, and no redirects. The app is intended for trusted local use; do not expose it to an untrusted network.
- Results are JSON stored in the relational database; Parquet, DuckDB, and object storage are not implemented. Analysis-run history and saved comparisons are persisted, but run results and parsed record summaries remain materialized in process memory.
